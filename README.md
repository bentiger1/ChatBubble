# chat bubble
a discord theme/mod that turns your chats into chat bubbles so it looks like most sites. this is my first time doing this so please reach out to me if u have any issues, you can join my discord if theirs any issues.

# install
### vencord/betterdiscord (or any client that supports theme files)
1. download the theme file, ChatBubble.css, or whatever version you have
2. drag ChatBubble.css into your theme folder. (there should be a button to open the theme folder in theme settings)
